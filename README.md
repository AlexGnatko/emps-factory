# EMPS Factory

The purpose of EMPS Factory is to provide tools for web server administrators
running multiple websites on a single web server. The websites can be EMPS4.5, 
EMPS6, custom PHP engines, WordPress, or even Django.

EMPS Factory includes an always-running service that executes "commands"
initiated by the server admin. The service runs as root, so it can do any
job at the server, so this function has to be secure.

EMPS Factory provides multiple helpful tools: website setup and configuration,
website migration from one EMPS Factory server to another, arbitrary OS
shell command execution, webserver and database usage stats collection
and presentation, etc.

Please study the project to fill in any gaps in this document as you
find or create a feature not covered here.
